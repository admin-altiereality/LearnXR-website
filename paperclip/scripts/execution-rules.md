# Autonomous Execution Rules — Altie Reality

## Core Principle

The company operates on **weekly autonomous cycles**. Each agent executes their loop independently, escalating only when thresholds are breached. The CEO intervenes on strategy, not operations.

## Self-Operating Rules

### 1. Task Generation
- Each agent generates their own weekly tasks from OKR key results
- Tasks must have: title, owner, priority (P0-P3), deadline, measurable completion criteria
- If a key result is on track (green), generate maintenance tasks
- If a key result is at risk (yellow), generate acceleration tasks with P1 priority
- If a key result is behind (red), generate recovery tasks with P0 priority + escalation

### 2. Self-Evaluation (Weekly)
Every Friday, each agent:
- Scores each KPI: Green / Yellow / Red
- Writes 3-line summary: what worked, what didn't, what changes next week
- Submits to reporting manager
- Two consecutive Reds → auto-escalate to CEO

### 3. Escalation Protocol

| Severity | Trigger | Action | Who Decides |
|----------|---------|--------|-------------|
| Low | KPI yellow for 1 week | Agent adjusts approach autonomously | Self |
| Medium | KPI red for 1 week, or yellow for 2+ weeks | Agent proposes recovery plan to manager | Manager |
| High | KPI red for 2+ weeks, or critical threshold breached | CEO convenes emergency review | CEO |
| Critical | Runway < 6 months, security breach, key person departure, ≥₹50L deal loss | Immediate CEO + full C-suite response | CEO |

### 4. Auto-Escalation Triggers (No Human Decision Required)

These automatically trigger notifications and response protocols:

- **Financial:** Burn rate > 120% of budget → CFO + CEO alert
- **Pipeline:** Weighted pipeline < ₹1.5Cr → CBDO + Enterprise Sales generate 5 outreach tasks each
- **Product:** Uptime < 99% → CTO gets P0 incident ticket
- **Marketing:** MQLs < 30/month for 2 consecutive weeks → CMO + Growth review channel mix
- **Sales:** Zero demos in a week → Enterprise Sales + CBDO outreach blitz
- **Compliance:** Missed filing deadline → CFO + CEO alert (reputational + legal risk)
- **HR:** 2 exits in same quarter → HR + CEO conduct retention analysis

### 5. Decision-Making Framework

**Level 1 — Agent decides autonomously:**
- Executing tasks within their weekly loop
- Spending within their approved budget
- Publishing content within brand guidelines
- Scheduling meetings and calls
- Running experiments within existing campaigns

**Level 2 — Manager approval required:**
- New budget requests
- Strategy changes within department
- New tool adoption
- Pricing deviations for specific deals
- Hiring for pre-approved roles

**Level 3 — CEO approval required:**
- New headcount requests
- Company-wide policy changes
- Budget reallocation > 20%
- Contracts > ₹10L
- Equity-related decisions
- Public relations and media

**Level 4 — Board/Advisor consultation:**
- Fundraising decisions
- Major pivots
- M&A / acqui-hire
- Board composition changes

### 6. Communication Rules

- **Async first:** All routine communication via Paperlip/Slack/email. No meetings for updates.
- **Meetings are for decisions:** If no decision is needed, write a doc/message instead.
- **Status updates auto-generate:** Dashboards pull live data. No manual status reports except Friday summaries.
- **Escalations in real-time:** Critical escalations are immediate (WhatsApp/call). Don't wait for the weekly cycle.
- **Transparency default:** All metrics, pipeline, financials visible to all agents (except salary data).

### 7. Feedback Loops

- **Weekly:** Friday self-evaluation → Monday planning (1-week feedback loop)
- **Monthly:** KPI trend analysis, process retrospective (4-week feedback loop)
- **Quarterly:** OKR scoring, strategy adjustment, performance review (13-week feedback loop)
- **Annual:** Full strategy review, team structure evaluation, compensation benchmarking

### 8. Resource Allocation Rules

When demand exceeds capacity:

1. **Priority filter:** Govt deals > B2B deals > B2C growth > internal projects
2. **Impact filter:** Revenue-generating > brand-building > operational efficiency
3. **Time filter:** Deals with deadline (tender submission, pilot start) > open pipeline
4. **CEO arbitration:** When two P0 priorities conflict, CEO decides within 24 hours

### 9. Failure Handling

When something fails:

1. **Acknowledge immediately.** No hiding. No blame.
2. **Diagnose within 24 hours.** Root cause, not symptoms.
3. **Fix within 48 hours** (for P0-P1). Document the fix and the lesson.
4. **Prevent recurrence.** What process/system change ensures this doesn't happen again?
5. **Share the learning.** Friday all-hands: "Here's what we learned from the [X] failure."
